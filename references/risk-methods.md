# 风险辨识与评估方法速查

本文件收录安全生产风险辨识与评估常用方法，用于输出风险评估结论时说明方法与分级依据。

## 方法选择速查

| 方法 | 全称 | 适用场景 | 输出 |
|---|---|---|---|
| SCL | 安全检查表法（Safety Checklist Analysis） | 静态设备、作业现场、管理制度的符合性检查 | 检查清单 + 不符合项 |
| JHA | 作业危害分析（Job Hazard Analysis） | 单个作业步骤的风险分析（检修、动火、高处作业等） | 步骤-危害-措施表 |
| LEC | 作业条件危险性评价法（格雷厄姆-金尼法） | 半定量评估作业环境风险 | D=L×E×C 分值 + 危险等级 |
| LS | 风险矩阵法（Likelihood × Severity） | 风险分级管控（双控机制常用） | 风险等级（四色分级） |
| HAZOP | 危险与可操作性分析（Hazard and Operability Study） | 化工工艺过程系统性风险分析 | 节点-偏差-原因-后果-措施表 |
| FMEA | 失效模式与影响分析 | 设备/系统可靠性风险 | 失效模式-影响-严重度 |

## LEC 法（D = L × E × C）

- **L（事故发生的可能性）**：0.1（实际不可能）~ 10（完全可以预料），常用 0.5/1/3/6/10
- **E（暴露于危险环境的频繁程度）**：0.5（非常罕见）~ 10（连续暴露），常用 0.5/1/2/3/6/10
- **C（发生事故产生的后果）**：1（引人注目）~ 100（大灾难，10 人以上死亡），常用 1/3/7/15/40/100
- **D 分级**：
  - D ≥ 320：极其危险，不能继续作业
  - 160 ≤ D < 320：高度危险，需立即整改
  - 70 ≤ D < 160：显著危险，需要整改
  - 20 ≤ D < 70：一般危险，需要注意
  - D < 20：稍有危险，可以接受

## LS 风险矩阵法（四色分级）

- **L（可能性）**：1（极低）~ 5（极高）
- **S（严重性）**：1（轻微）~ 5（灾难）
- **R = L × S 分级**：
  - R ≥ 15：重大风险（红）
  - 10 ≤ R < 15：较大风险（橙）
  - 5 ≤ R < 10：一般风险（黄）
  - R < 5：低风险（蓝）

## JHA 操作步骤

1. 分解作业步骤（通常 5~10 步，步数过多可合并）
2. 识别每步存在的危害（人、机、料、法、环五个维度）
3. 分析危害可能造成的事故后果
4. 制定控制措施（消除 → 替代 → 工程控制 → 管理控制 → 个体防护，按层级优先）
5. 形成 JHA 表：`步骤 | 危害 | 后果 | 控制措施 | 责任人`

## 重大危险源辨识

- 依据 GB 18218-2018《危险化学品重大危险源辨识》，单元内危险化学品数量达到或超过临界量即构成重大危险源
- 辨识流程：划分单元 → 确定物质 → 查临界量 → 计算比值（S=∑qi/Qi）→ S≥1 为重大危险源
- 构成重大危险源须：登记建档、定期检测评估监控、制定应急预案并备案（《安全生产法》第四十条）

## 输出示例（LS 矩阵）

```
作业活动：储罐区动火作业
危害：油气积聚遇明火引发火灾爆炸
L=4（频繁发生可能），S=5（灾难性后果）→ R=20 → 重大风险（红）
管控措施：办理动火审批、气体检测合格（LEL<20%）、配备消防器材、专人监护
```
