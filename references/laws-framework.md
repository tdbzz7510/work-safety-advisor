# 中国安全生产法规体系速查

本文件用于快速定位安全生产咨询中适用的法规标准。法规会定期修订，使用前须核对最新版本（以全国人大、应急管理部、国家标准委发布为准）。

## 法规体系层级

```
法律（全国人大及其常委会）
  └─ 行政法规（国务院）
       └─ 部门规章（应急管理部等部委）
            └─ 国家标准 GB / 行业标准（AQ、JG、MT 等）
                 └─ 地方性法规 / 地方政府规章 / 企业制度
```

上位法优先；下位法不得与上位法冲突。同一事项有多个标准时，按「国家标准 > 行业标准 > 地方标准」及最新发布版本执行。

## 核心法律（法律层级）

| 法律 | 要点 |
|---|---|
| 《中华人民共和国安全生产法》（2021 修正，最新） | 核心法律。确立「三管三必须」、企业主体责任、双重预防机制、全员安全生产责任制、安全生产标准化；主要负责人第一责任人职责（第 21 条等）；对高危行业强制安责险 |
| 《中华人民共和国职业病防治法》（2018 修正） | 职业病危害因素识别与控制、职业健康监护、职业病诊断鉴定 |
| 《中华人民共和国消防法》（2021 修正） | 消防责任、火灾预防、消防设施维护、消防安全培训与演练 |
| 《中华人民共和国劳动法》 | 劳动安全卫生、工时、女职工与未成年工特殊保护 |
| 《中华人民共和国特种设备安全法》（2013） | 特种设备（锅炉、压力容器、电梯、起重机械等）生产、使用、检验检测责任 |
| 《中华人民共和国突发事件应对法》 | 突发事件预防与应急准备、监测预警、应急处置与救援 |

## 核心行政法规

- 《生产安全事故报告和调查处理条例》（国务院令第 493 号）— 事故分级（特别重大/重大/较大/一般）、报告时限（1 小时）、调查处理程序
- 《安全生产许可证条例》— 高危行业（矿山、建筑施工、危化品、烟花爆竹、民用爆破）安全生产许可
- 《危险化学品安全管理条例》（国务院令第 591 号）— 危化品生产、储存、经营、运输全链条管理
- 《建设工程安全生产管理条例》（国务院令第 393 号）— 建筑施工安全责任划分
- 《使用有毒物品作业场所劳动保护条例》
- 《生产安全事故应急条例》（国务院令第 708 号）— 应急预案编制、演练、应急物资配备

## 核心部门规章与规范性文件

- 《工贸企业重大事故隐患判定标准》（应急管理部令第 10 号）— 工贸行业重大隐患判定
- 《化工和危险化学品生产经营单位重大生产安全事故隐患判定标准（试行）》
- 《安全生产事故隐患排查治理暂行规定》（安监总局令第 16 号）— 隐患排查治理制度、重大隐患报告
- 《生产经营单位安全培训规定》— 三类人员（主要负责人、安全管理人员、特种作业人员）培训要求
- 《特种作业人员安全技术培训考核管理规定》（安监总局令第 30 号）— 特种作业目录、复审周期（3 年复审）
- 《用人单位劳动防护用品管理规范》— 劳动防护用品配备与使用

## 核心标准（GB 层级）

| 标准 | 领域 |
|---|---|
| GB/T 33000-2016《企业安全生产标准化基本规范》 | 安全生产标准化创建核心依据 |
| GB 6441-1986《企业职工伤亡事故分类》 | 事故类别划分（20 类） |
| GB 6442-1986《企业职工伤亡事故调查分析规则》 | 事故调查分析方法 |
| GB 18218-2018《危险化学品重大危险源辨识》 | 重大危险源辨识临界量 |
| GB/T 45001-2020（对应 ISO 45001:2018） | 职业健康安全管理体系 |
| GB 39800.1-2020《个体防护装备配备规范 第1部分》 | 防护装备配备 |
| GBZ 2.1-2019《工作场所有害因素职业接触限值 第1部分》 | 化学有害因素限值 |
| GBZ 188-2014《职业健康监护技术规范》 | 职业健康监护 |

## 高危行业专项规范

- 化工：HAZOP 分析（GB/T 35320）、重大危险源辨识（GB 18218）、双重预防机制建设指南
- 建筑：JGJ 59-2011《建筑施工安全检查标准》、危大工程（住建部令第 37 号）
- 矿山：《金属非金属矿山安全规程》（GB 16423）、《煤矿安全规程》（2022 修订）
- 冶金：《冶金企业和有色金属企业安全生产规定》
